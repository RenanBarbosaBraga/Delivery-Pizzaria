# Delivery-Pizzaria

API REST desenvolvida em Python com FastAPI para estudo e prática de desenvolvimento de back-end, autenticação e integração com banco de dados utilizando SQLAlchemy.

## Sobre o projeto

O Delivery-Pizzaria é um projeto desenvolvido com o objetivo de praticar conceitos de desenvolvimento de APIs utilizando FastAPI.

A aplicação simula a estrutura básica de um sistema de delivery, permitindo trabalhar com usuários, autenticação e pedidos.

O projeto também serve como ambiente de estudo para conceitos importantes de desenvolvimento back-end, como:

- Criação de APIs REST
- Rotas e endpoints
- Autenticação de usuários
- Modelagem de dados
- Integração com banco de dados
- SQLAlchemy
- Organização de código em diferentes módulos
